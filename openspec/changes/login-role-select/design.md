## Context

当前登录页面仅支持微信登录，缺少角色选择和手机号登录功能。需要增加房东/住户角色选择，并通过虚拟账户支持测试。

## Goals / Non-Goals

**Goals:**
- 登录页增加房东/住户角色 Tab 切换
- 实现手机号+验证码登录
- 首次登录自动创建虚拟账户
- 角色区分跳转页面

**Non-Goals:**
- 微信登录功能保持不变
- 短信验证码真实发送（开发环境固定验证码）
- 复杂的权限管理系统

## Decisions

1. **登录方式选择**: 采用手机号+验证码，简化测试流程
2. **验证码策略**: 开发环境固定 123456/666666，生产环境接入短信服务
3. **角色存储**: 用户角色存储在 User 表的 role 字段
4. **虚拟账户**: 首次登录自动创建，无需预先注册

## Risks / Trade-offs

- [风险] 固定验证码不安全 → [缓解] 生产环境替换为真实短信验证码
- [风险] 虚拟账户无法区分真实用户 → [缓解] 后续接入真实登录后可废弃
