## ADDED Requirements

### Requirement: 虚拟账户自动创建

系统 SHALL 在用户首次登录时自动创建虚拟账户，供测试使用。

#### Scenario: 房东虚拟账户
- **WHEN** 用户选择房东角色并使用新手机号首次登录
- **THEN** 系统创建房东角色的虚拟账户，默认昵称为"房东用户"

#### Scenario: 住户虚拟账户
- **WHEN** 用户选择住户角色并使用新手机号首次登录
- **THEN** 系统创建住户角色的虚拟账户，默认昵称为"住户用户"

#### Scenario: 虚拟账户权限
- **WHEN** 虚拟账户登录成功后
- **THEN** 账户具有对应角色的完整权限，可正常操作系统

#### Scenario: 验证码固定
- **WHEN** 开发环境下用户登录
- **THEN** 验证码固定为 123456 或 666666
