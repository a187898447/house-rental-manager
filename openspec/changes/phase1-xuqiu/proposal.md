# 租房小程序 Phase 1 需求规范

## 为什么

Phase 1 是租房小程序的核心基础功能，实现房源、租客、租金的数字化管理，替代传统记事本/Excel管理方式。

## 需求变更

### Phase 1 核心模块

| 编号 | 功能 | 说明 |
|------|------|------|
| P1-01 | 微信一键登录 | 微信授权获取OpenID，需绑定手机号 |
| P1-02 | 房源录入 | 添加房源信息（楼栋、单元、房号、面积、租金、押金） |
| P1-03 | 房源列表 | 按标签页查看：未出租/已出租(未缴费)/已出租(已缴费) |
| P1-04 | 房源编辑/删除 | 编辑房源详情，逻辑删除 |
| P1-05 | 入住登记 | 录入租客信息（姓名、电话、租期、租金支付方式） |
| P1-06 | 租客列表 | 查看当前/历史租客 |
| P1-07 | 退租办理 | 记录退租信息 |
| P1-08 | 租金记录 | 记录每笔租金收入（默认月付，按天计算） |
| P1-09 | 收租提醒 | 每月固定日期提醒收租（推送通知） |
| P1-10 | 租金统计 | 按月/按年统计收租情况 |

## Capabilities

- **New Capabilities**:
  - wechat-login: 微信一键登录
  - property-management: 房源管理（录入/列表/编辑/删除）
  - tenant-management: 租客管理（入住/列表/退租）
  - rent-management: 租金管理（记录/提醒/统计）

## 影响范围

- **后端**: rental-user, rental-property, rental-bill 服务
- **前端**: 登录、房源、租客、租金相关页面
- **数据库**: user, property, tenant, rent_record 表
