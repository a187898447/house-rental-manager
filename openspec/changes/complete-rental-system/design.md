## Context

租房小程序需要实现完整的租赁管理流程，包括房东端和租客端，基于 UniApp + Spring Boot 微服务架构。

## Goals / Non-Goals

**Goals:**
- 实现完整的房东端功能（房源、租客、租金、押金、水电、费用、报修、统计）
- 实现完整的租客端功能（合同、账单、缴费、报修、联系房东）
- 支持微信登录和手机号登录
- 支持电子合同和手写签名
- 支持数据统计和收据导出

**Non-Goals:**
- 微信小程序具体配置（AppID等）
- 真实短信验证码发送（开发环境固定验证码）
- 微信公众号接入

## Decisions

1. **前端框架**: UniApp (Vue 3 + TypeScript)
2. **后端架构**: Spring Cloud 微服务
3. **数据库**: MySQL 8.0
4. **登录方式**: 微信登录 + 手机号验证码登录
5. **角色区分**: landlord (房东) / tenant (住户)

## Risks / Trade-offs

- [风险] 开发环境验证码固定 → [缓解] 生产环境接入真实短信服务
- [风险] 微信支付需商户号 → [缓解] 先实现模拟支付
