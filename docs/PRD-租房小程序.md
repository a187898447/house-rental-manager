## 1. 产品概述

### 1.1 产品定位

一款面向**个人房东**的房屋租赁管理工具小程序，帮助房东高效管理房源、租客、租金和水电账单，替代传统的记事本/Excel管理方式。

### 1.2 目标用户

| 用户类型 | 特征 | 规模 |
|---------|------|------|
| 个人房东 | 1-10套房，自主管理 | 最大群体 |
| 二房东/包租公 | 长租运营，批量管理 | 中等群体 |
| 家庭共有房产 | 家人协同管理 | 较小群体 |

### 1.3 核心价值主张

> **让房东从记事本迁移到小程序，实现房源数字化管理**

- 🔄 **替代记事本**：数据云端存储，永不丢失
- ⏰ **自动提醒**：收租、水电不再忘记
- 📊 **数据统计**：每月收了多少，一目了然
- 📄 **电子收据**：一键导出，环保高效

| 功能 | 说明 |

| 房源搜索 | 按地址、楼栋、状态筛选 |
| **房源列表** | **按标签页查看：未出租 / 已出租(未缴费) / 已出租(已缴费)** |

#### 2.2.2 租客管理

| 功能 | 说明 |

| 入住登记 | 租客姓名、电话、身份证（选填）、起止租期、租金支付方式 |

| 租客搜索 | 按姓名、电话搜索 |

#### 2.2.3 租金管理

| 功能 | 说明 |
|------|------|
| 租金记录 | 记录：房源、租客、金额、支付日期、支付方式（现金/转账） |
| **按天计算** | **月中入住/退租，按租住天数比例计算租金** |
| 收租提醒 | 设置每月提醒日期，系统自动推送通知 |
| **催租提醒** | **租客逾期未付，系统自动提醒（3次后通知房东）** |

#### 2.2.4 押金管理

## 6. 竞品分析

| 竞品 | 优点 | 缺点 |
|------|------|------|
| 记事本 | 无需学习 | 易丢失、无提醒、难统计 |
| Excel/表格 | 可统计 | 不方便查看、难共享 |
| 租房平台 | 流量大 | 面向租客，非房东工具 |
| 现有房东工具 | 功能多 | 复杂、收费、面向B端 |

**我们的机会**：轻量、免费、简单、专注个人房东
